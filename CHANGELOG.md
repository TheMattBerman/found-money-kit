# Changelog

## 0.1.0 (initial public release)

Found Money turns CRM and billing records into an offline Recovery Room with ranked opportunities, supporting evidence, campaign drafts, and a printable report.

- Supports example scenarios for subscription, ecommerce, and service businesses, plus normalized HubSpot and Stripe file inputs.
- Separates observed amounts, modeled estimates, recorded deal values, and unpriced opportunities. Currencies remain separate.
- Includes business-profile intake, account identity checks, recovery offers, and campaign handoffs for owner review.
- Provides a responsive Money Map, keyboard navigation, reduced-motion support, and PDF output.
- Keeps inputs read-only. The kit does not send messages, launch campaigns, or write back to connected systems.
